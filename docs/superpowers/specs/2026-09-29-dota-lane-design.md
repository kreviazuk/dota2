# 中路风云（Dota-like 3v3 单路手游）设计文档

- 日期：2026-09-29
- 状态：已确认（用户已同意第 1–4 段设计，并授权后续全部自动执行）
- 数值基准：Dota 2 **7.41f**。原始数据见 `docs/research/dota2-reference.md`（斧王、物品、线上规则）和 `docs/research/dota2-heroes.md`（其余 9 名英雄）。**本文未写明调整的数值，一律以这两份资料为准。**

## 1. 目标与范围

### 1.1 一句话描述
横屏手机游戏：3v3，只有一条竖直的中路；玩家在下方（天辉），电脑在上方（夜魇）。先推倒对方基地的一方获胜。一局 15–20 分钟。

### 1.2 已确认的需求
| 项 | 决定 |
|---|---|
| 对局 | 3v3，同一条中路。玩家操作 1 名英雄，其余 5 名（2 名队友、3 名敌人）由 AI 控制 |
| 英雄池 | 10 名：斧王 Axe、斯温 Sven、帕吉 Pudge、主宰 Juggernaut、幻影刺客 Phantom Assassin、卓尔游侠 Drow Ranger、影魔 Shadow Fiend、莉娜 Lina、宙斯 Zeus、水晶室女 Crystal Maiden |
| 选人 | 玩家选 1 名，其余由电脑分配；同一方不重复，两方之间可以重复 |
| 建筑 | 每方 3 座外塔（T1/T2/T3）、2 座基地塔（T4）、1 个基地（遗迹） |
| 兵线 | 双方都刷小兵；敌方定期在兵线里混入精英怪 |
| 时长 | 一局 15–20 分钟 |
| 物品 | 约 30 件成品 + 5 种消耗品 + 所需配件，沿用 Dota 合成关系，随时随地可买 |
| 难度 | 开局选简单 / 普通 / 困难 |
| 平台 | 先做网页版，最后用 Capacitor 打包成安卓 APK；横屏 |
| 操作 | 左侧虚拟摇杆移动，右侧普攻键 + 技能键 + 物品栏 |
| 画面 | 2D 俯视，美术全部由代码绘制（不使用 Dota 版权素材） |

### 1.3 不做的内容（第一版）
战争迷雾、反补、买活、多条路、野区、联网对战、账号和成长系统、信使、神秘商店（所有物品都在同一个商店里）、幻象类物品（幻影斧等）。

## 2. 技术架构

### 2.1 技术栈
- TypeScript（strict）+ Vite；单元测试用 Vitest；无第三方游戏框架。
- 渲染：Canvas 2D；界面：DOM 覆盖层（原生 TS，不引入 UI 框架）。
- 打包：Capacitor → Android APK。

### 2.2 目录结构
```
src/
├── sim/                 纯逻辑，禁止引用 DOM / window / Canvas
│   ├── core/            Vec2、种子随机数（mulberry32）、固定步长时钟、事件总线、ID 分配
│   ├── world.ts         World：所有实体、游戏时间、胜负状态、step(dt)
│   ├── entities/        Unit（基类）、Hero、Creep、Elite、Building、Projectile、AreaEffect
│   ├── systems/         movement、combat、abilities、buffs、economy、spawner、buildings、victory
│   ├── heroes/          每个英雄一个文件：数据 + 技能行为
│   ├── items/           物品数据表 + 主动/被动效果
│   ├── elites/          精英怪数据 + 技能
│   ├── data/            balance.ts（全部可调平衡参数）、map.ts（地图布局）、xpTable.ts
│   └── commands.ts      指令类型
├── ai/                  团队策略、个人战术、技能施放、出装加点、难度参数
├── render/              Camera、地图绘制、单位绘制、特效粒子、飘字、小地图
├── ui/                  HUD、摇杆、技能键、商店、选人、天赋弹窗、结算、主菜单
├── input/               触屏 / 键鼠 → Command
├── audio/               WebAudio 合成音效（打磨阶段）
└── main.ts              启动、场景切换、主循环
tools/
└── simulate.ts          Node 无画面批量对战，输出平衡报告
tests/                   Vitest 单元测试（主要测 sim）
```

### 2.3 核心原则
1. **逻辑与画面分离**：`sim/` 和 `ai/` 只依赖纯 TS，可以在 Node 里无画面运行。
2. **统一指令**：玩家和 AI 都只能通过 `Command` 操作英雄（见 2.4）。AI 不读取任何玩家拿不到的信息（本游戏没有迷雾，所以 AI 可以读整个 World 的状态）。
3. **固定步长**：逻辑每秒 30 次（`TICK = 1/30`）；渲染层用 requestAnimationFrame，在两次逻辑状态之间插值。
4. **可复现**：所有随机都走 `world.rng`（种子随机数）。同一个种子加同样的指令序列，得到完全相同的对局。
5. **数据驱动**：数值集中放在数据表和 `balance.ts` 里；特殊效果写成函数。
6. **事件驱动表现**：sim 通过事件（damage、death、cast、levelUp、goldGain、buildingDestroyed……）通知渲染层和音效层，sim 本身不知道画面的存在。

### 2.4 指令（Command）
```ts
type Command =
  | { type: 'move'; dir: Vec2 | null }                       // 摇杆方向（单位向量）；null = 停止
  | { type: 'attack'; mode: 'smart' | 'lastHit' | 'building'; targetId?: number }
  | { type: 'cast'; slot: AbilitySlot; target?: CastTarget }  // 'Q'|'W'|'E'|'R'|'X1'|'X2'
  | { type: 'toggle'; slot: AbilitySlot }
  | { type: 'useItem'; index: number; target?: CastTarget }
  | { type: 'learn'; slot: AbilitySlot }
  | { type: 'pickTalent'; tier: 10 | 15 | 20 | 25; side: 0 | 1 }
  | { type: 'buy'; itemId: string } | { type: 'sell'; index: number }
  | { type: 'recall' }
type CastTarget = { unitId?: number; point?: Vec2; dir?: Vec2 }
```
没有给目标时，sim 按"智能施法"规则自动选（见 6.2）。

### 2.5 坐标系
世界单位等于 Dota 单位。x 向右、y 向下。地图宽 3000、高 10000。天辉（玩家方）在下（y 大），夜魇在上。

## 4. 兵线

### 4.1 刷兵
- 第一波在 0:10 出发，之后每 **25 秒**一波。
- 每波组成：3 近战 + 2 远程；3:00 起每 4 波加 1 辆攻城车；6:00 起 +1 近战；12:00 起 +1 远程。
- 小兵沿道路中线向敌方前进。遇到敌人（小兵索敌 500、远程 600、攻城车 800）就攻击；敌人离开追击范围 1.5 倍后放弃，回到道路继续前进。
- 小兵仇恨：敌方英雄**普攻**我方英雄时，该英雄 500 范围内的敌方小兵转火它，持续 2 秒，冷却 3 秒。只放技能不会引起仇恨。
- 开局保护：两边第一波小兵相遇之前，不会被英雄仇恨吸引，也不受嘲讽。

|---|---|---|---|---|---|---|---|---|---|
| 近战兵 | 550 | 2 | 0 | 21 | 1.0 | 100 | 325 | 36 | 57 |
| 远程兵 | 300 | 0 | 0 | 24 | 1.0 | 500 | 325 | 48 | 69 |
| 攻城车 | 935 | 0 | 80% | 40 | 3.0 | 690 | 325 | 65 | 88 |

- 伤害修正：近战兵打英雄 ×0.75；远程兵打小兵 ×1.5、打英雄 ×0.5；攻城车受英雄攻击 ×0.5。

## 6. 英雄与技能

### 6.1 英雄数值模型
- 属性（7.41f）：每点力量 +22 生命、+0.1 回血；每点敏捷 +1/6 护甲、+1 攻速；每点智力 +12 魔法、+0.05 回蓝、+0.1% 魔抗；每点主属性 +1 攻击力。基础生命 120、基础魔法 75、基础魔抗 25%。
- 攻击：攻击间隔 = BAT / (攻速/100)，攻速范围 20–700。有攻击前摇（按资料里的数值）；远程攻击发射弹道，弹道追踪目标。
- 护甲减伤 = 0.06 × 护甲 / (1 + 0.06 × |护甲|)；多个魔抗来源乘算；纯粹伤害不减免。
- 升级：满级 25，每级 1 技能点。QWE 各 4 级，R 在 6/12/18 级可学；学满后剩余的点自动变成"属性加成"（每点 +2 全属性）。
- 天赋：10/15/20/25 级各二选一（原版天赋树）。
- 先天技能：全部保留，数值按英雄等级成长。
- 移速范围 100–550。

### 6.2 施法与操作
- **轻点技能键 = 智能施法**：
  - 单位目标：施法距离内，优先选最近的敌方英雄，其次最近的敌方单位；技能行为可以覆盖这个规则（例如淘汰之刃优先选能斩杀的目标）。
  - 方向技能：朝最近的敌方英雄方向，没有英雄时朝面向方向。
  - 地点技能：落在最近的敌方英雄脚下（限制在施法距离内），没有英雄时落在最近的敌方单位脚下。
- **按住拖动** = 手动瞄准：显示方向线、落点圈或锁定目标高亮；松手释放；拖到"取消区"取消。
- **施法距离外**：英雄先自动走到施法距离内再放。移动摇杆可以打断。
- **普攻键（智能）**：攻击射程 + 200 范围内，优先打敌方英雄，其次最近的小兵，最后是建筑。
- **补刀键**：攻击射程 + 200 范围内，打一下就能打死的、血量最低的敌方小兵；没有这样的小兵时，打血量最低的敌方小兵。
- **推塔键**：打射程 + 200 范围内的敌方建筑。
- **站立自动攻击**：没有移动也没有指令时，自动攻击射程内的敌人（可在设置里关闭）。
- **回城**：引导 5 秒，传回泉水；受到伤害或移动都会打断；冷却 0 秒。

### 6.4 阿哈利姆神杖 / 魔晶
10 名英雄的神杖和魔晶效果全部实现（数值见资料）。影响视野的部分（例如宙斯雷击的视野）忽略。

### 6.5 状态（Buff）系统
通用 Modifier：来源、持续时间、叠层、刷新规则、是否可驱散、属性修正（加法或乘法）、周期回调（onInterval）、事件钩子（onAttackLanded、onAttacked、onDamageTaken、onDeath、onKill……）。

内置状态：眩晕、减速（移速/攻速）、缠绕、沉默、缴械、嘲讽（强制攻击来源）、恐惧（远离来源）、减益免疫、无敌、隐身/模糊、击退（带位移曲线）、护盾（按伤害类型吸收）、伤害格挡、闪避、暴击、吸血、反弹、持续伤害。

驱散分两级：弱驱散移除可驱散的增益或减益；强驱散还能移除眩晕等控制。

## 7. 物品与商店

## 9. 电脑 AI

### 9.1 结构（队友和敌人共用）
1. **团队策略层**（每 1 秒）：根据兵线前沿位置、双方塔的血量、英雄存活人数和血量、等级和净资产对比、精英怪位置，从 对线 / 推进 / 防守 / 撤退 / 团战 / 集火精英 中选择团队模式。
2. **个人战术层**（每 0.2 秒 + 反应延迟）：对候选行动打分（utility AI），选分数最高的执行。候选行动：
   - 补刀
   - 消耗敌方英雄
   - 跟随团队目标
   - 躲塔的仇恨（不在敌塔射程内攻击英雄，除非能击杀）
   - 低血量时后撤或回城（阈值随难度变化）
   - 吃药
   - 追击残血敌人
   - 保护残血队友
3. **技能施放层**：每个技能都有 `aiShouldCast(ctx)` 函数，返回是否施放和目标；方向和地点技能带移动预判（预判程度随难度变化）。
4. **出装与加点**：按英雄的推荐出装顺序和预设加点顺序执行；天赋使用预设选择。
5. 玩家控制的英雄不使用 AI。

### 9.2 难度（只影响夜魇，天辉队友固定为普通）
| 参数 | 简单 | 普通 | 困难 |
|---|---|---|---|
| 反应延迟 | 0.6s | 0.35s | 0.15s |
| 技能预判 | 0%（外加随机偏差 ±150） | 50% | 100% |
| 补刀成功率 | 50% | 75% | 95% |
| 集火与连招 | 不会 | 偶尔（50%） | 会 |
| 撤退阈值 | 血量 20% | 血量 30% | 按威胁评估 |
| 精英怪强度 | ×0.8 | ×1.0 | ×1.25 |
| 敌方金钱和经验 | ×0.9 | ×1.0 | ×1.15 |

**平衡目标**：把玩家位置也换成普通 AI 跑模拟，天辉胜率应为：简单约 70%、普通约 45%、困难约 25%（允许 ±8%）。

### 9.3 选人
- 玩家从 10 名英雄里选 1 名。
- 电脑补齐其余位置：同一方不重复；尽量保证每方至少有 1 名力量英雄和 1 名带硬控的英雄。

## 10. 界面与画面

### 10.1 场景流程
主菜单（开始游戏 / 设置）→ 选难度 → 选英雄（10 张卡片，显示属性、定位、4 个技能说明）→ 对局 → 结算（胜负、时长、每个英雄的 KDA、补刀、净资产、出装）→ 返回主菜单。

```
┌────────────────────────────────────────────────────────────┐
```

- 摇杆是浮动式的：左半屏任意位置按下就出现。
- 技能键显示冷却遮罩、魔法不足时变灰、可升级时显示"+"、开关技能开启时高亮；影魔的 Q 显示充能次数。
- 天赋弹窗：升到 10/15/20/25 级时，在技能区上方弹出二选一。
- 死亡时画面变灰，显示复活倒计时，可以继续买东西。

- 键鼠（网页开发和测试用）：WASD 移动；QWER 技能；Space 普攻；1–6 物品；B 商店；T 回城；Ctrl+QWER 加点。

### 10.3 镜头
- 跟随玩家英雄，并向敌方方向（上方）偏移 20% 屏高，让玩家看到更远的前方。
- 缩放：屏幕高度对应约 1400 世界单位；DPR 最高按 2 处理。
- 大招命中时轻微震屏。

### 10.4 代码美术风格
- 俯视加伪 3D：单位都有椭圆阴影；塔和遗迹按高度偏移绘制，看起来有立体感。
- 地面：道路是土石纹理（预渲染成噪声图块并缓存），两侧是树丛（程序生成的深绿圆簇）和悬崖；河道带动态波纹。天辉一侧偏绿色调，夜魇一侧偏暗红和焦土色调。
- 英雄：底座圆环用阵营色（天辉绿、夜魇红），主体由几何图形拼成，每个英雄有辨识色和标志物：
  - 斧王：红色，巨斧
  - 斯温：蓝色盔甲，大剑
  - 帕吉：肉粉色、体型大，钩子
  - 主宰：橙色面具，刀
  - 幻影刺客：紫色斗篷，短刃
  - 卓尔：冰蓝色，弓
  - 影魔：黑红色，暗影翼
  - 莉娜：火红色长发
  - 宙斯：白金色，闪电光环
  - 水晶室女：浅蓝色，冰晶法杖
- 头顶显示血条（己方绿、敌方红）、蓝条和等级。
- 特效：粒子系统（火焰、冰霜、闪电、血、灵魂），加上发光（`globalCompositeOperation = 'lighter'`）和冲击波圆环。
- 飘字：物理伤害白色、魔法蓝色、纯粹金色、暴击放大红字、治疗绿色、金钱 "+xx" 金色。
- 性能：静态地图层预渲染到离屏 Canvas；粒子和飘字用对象池；中端安卓机目标 60fps。

### 10.5 音效（打磨阶段）
用 WebAudio 合成简短音效：普攻、技能、升级、金钱、塔倒、胜利/失败。默认开启音效，可以关闭。

## 11. 平衡测试

### 11.1 模拟工具
```
npm run sim -- --games 200 --difficulty normal --seed 1 [--heroes axe,lina,...] [--report out.md]
```
6 个位置全部由 AI 控制，关闭渲染，尽可能快地跑。输出：
- 对局时长分布，以及胜负原因（基地被推 / 超时判定）
- 天辉胜率，各英雄的出场胜率
- 3/6/10/14 分钟时的平均等级和净资产，与 5.1 的目标表对比
- 各座塔被推倒的平均时间
- 各英雄的场均 KDA、伤害，以及出装到位的时间

安全阀：单局超过 40 分钟强制结束，按"建筑血量 + 净资产"判定胜负，并在报告里标红。

### 11.2 调参流程
先调经济和节奏系数，让时长和等级、净资产曲线达标；再调单个英雄（胜率偏离平均值超过 8% 的英雄优先调）；最后调难度系数，让三档胜率达标。每次调参的结果记录到 `docs/balance/balance-log.md`。

## 12. 测试策略
- **单元测试（Vitest）**：
  - 公式：护甲、魔抗、攻击间隔、属性换算、经验表
  - 伤害和状态：暴击、闪避、护盾、驱散
  - 每个英雄每个技能至少 1 个行为测试
  - 物品：合成、买卖、主动效果
  - 经济：补刀分钱、击杀赏金
  - 建筑：无敌链、偷塔保护
  - 胜负判定
- **确定性测试**：同一个种子跑两遍，结果完全一致。
- **冒烟模拟**：CI 脚本跑 10 局，每局都必须在限定时间内结束且不报错。
- **浏览器验证**：用 Chrome DevTools 截图检查 HUD 布局，模拟手机横屏尺寸，并做性能采样。
