# Dota 2 英雄参考数据（9 名英雄，单路中路 3v3 手游设计参考）

> **数据版本：Dota 2 7.41f（2026-09-15 发布，截至 2026-09-29 仍为最新）**
>
> 本文只整理数据，不涉及代码。斧王、物品、线上规则见同目录 `dota2-reference.md`。
>
> **数据来源（可信度从高到低）**
> 1. **游戏原始数据文件**：`scripts/npc/heroes/npc_dota_hero_*.txt`（含 `AbilityDefinitions`、`hero_levelup` 等字段），通过 GitHub `dotabuff/d2vpkr` 镜像获取（镜像更新于 2026-09-25，晚于 7.41f）。
> 2. **Valve 官方数据接口**：`dota2.com/datafeed/herodata`（中英文，含技能数值/天赋/A杖/魔晶说明）、`patchnotes`（逐条核对 7.40 ~ 7.41f 的改动，确认上述数值已包含 7.41f）。
> 3. **dota2.fandom.com**：多数页面停留在 7.33~7.36，**只用于机制说明**（比如肉钩的自我禁锢、无敌斩的斩击间隔公式），数值一律以 1、2 为准。Liquipedia 本次访问被限流（HTTP 429），没有使用。
>
> **标注约定**
> - `a/b/c/d`：技能 1/2/3/4 级数值（大招为 1/2/3 级）。
> - `(待确认)`：来源之间有出入，或数据文件里有但含义不明确。
> - 距离单位是 Dota 的 unit（近战攻击距离 150，英雄碰撞半径约 24~27）。
> - 【A杖】= 阿哈利姆神杖 (Aghanim's Scepter)；【魔晶】= 阿哈利姆魔晶 (Aghanim's Shard)；前摇 = 施法前摇 (Cast Point)。

## 0. 通用规则（7.40 ~ 7.41 的重要变化）

| 项目 | 当前规则 | 对本项目的意义 |
|---|---|---|
| 命石 (Facets) | **7.41 已从游戏中移除**。数据文件里残留的命石字段都标记为 `Deprecated` | 本文不列命石，每个英雄只有 1 套技能 |
| 先天技能 (Innate) | 从 1 级起就有，不占技能点。7.41 起不再随其他技能等级成长，改为固定值，或**随英雄等级成长**：`值 = 基础值 + 增量 × 英雄等级`（1 级就已加上一次增量）；影魔的"支配死灵"是每 6 级增加一次 | 实现时需要按英雄等级算数值 |
| 天赋 | 7.40 起天赋**不消耗技能点**：10/15/20/25 级各选一侧，27~30 级自动补齐另一侧 | 下文每个英雄都有天赋表 |
| 属性换算 | 1 力量 = 22 生命、0.1 生命恢复（fandom 写的是 0.09，**待确认**；Valve 官方数据接口和 Liquipedia 都按 0.1 计算）；1 敏捷 = 1/6 护甲、1 攻速；1 智力 = 12 魔法、0.05 魔法恢复、0.1% 魔抗；每点**主属性** +1 攻击力 | 基础生命 120、基础魔法 75、基础魔抗 25% |
| 攻击间隔 | `攻击间隔 = 基础攻击间隔BAT / (攻速/100)`，其中攻速 = 基础攻速 + 敏捷 | 下文"1 级攻击间隔"按此计算 |

### 移动端操控约定（下文"手游改编"一列用这些简称）

| 简称 | 对应 Dota 目标类型 | 建议操作 |
|---|---|---|
| **自动锁定** | 单位目标 (Unit Target) | 轻点 = 自动选施法距离内最近的敌方英雄（没有英雄就选最近的单位）；按住技能键拖动可以切换目标 |
| **方向技能** | 指向地点、实际是直线弹道 (Point/Directional) | 按住技能键拖出方向指示线，松手释放；轻点 = 朝最近敌方英雄方向释放 |
| **地点范围** | 地点 AoE (Point AoE) | 按住技能键拖动落点圆圈（限制在施法距离内），松手释放；轻点 = 落在最近敌方英雄脚下 |
| **即时** | 无目标 (No Target) | 轻点立即释放 |
| **被动** | Passive | 没有按钮，或者只显示一个状态图标 |
| **开关** | 开关技能 (Toggle) | 点一下开，再点一下关，按钮高亮表示开启 |
| **引导** | 持续施法 (Channeled) | 轻点开始；推动移动摇杆或被眩晕/沉默时中断 |

### 11.2 帕吉：肉钩 (Meat Hook) 与腐肉堆积 (Flesh Heap)

**肉钩的具体规则**
- 直线弹道，不追踪。速度 1600，搜索半径 100（以钩尖为圆心），最大飞行距离 1300，因此最远能钩到约 1400 距离的单位；飞满全程约 0.81s。
- 只在**伸出**的过程中判定碰撞，收回时不判定。钩住第一个碰到的单位（敌方、友方都可以，隐身单位也能钩到），不能钩远古单位、无敌或隐藏单位、建筑。
- 可以穿过树木、悬崖、地形，也会把目标拖过去。
- 命中敌人：先造成伤害（纯粹 150/220/290/360），再控制。**拉回的整个过程中目标被完全控制**（会打断持续施法）。目标最终被放到帕吉身边。非英雄单位（小兵、野怪）被直接秒杀。
- 命中友军：只拉回，不造成伤害，也不控制。
- **帕吉自我禁锢**：出钩后帕吉不能行动，直到钩子飞到最大距离的 65%（约 0.53s）；如果钩子提前钩中单位，立即解除。
- 命中后在目标位置提供 500 半径飞行视野 4s。
- 魔晶：追加"拉拽距离 × 20%"的伤害；钩中友军时冷却 −50%。
- 手游建议：用明显的直线指示器，钩子做成真实飞行的碰撞体（半径约 100 的圆）。拉回过程让目标跟着钩尖移动，结束时落在帕吉面前约 100~150 距离处。

**腐肉堆积（先天）与肉盾（E 技能）**
- 7.36 起原来的"腐肉堆积"拆成了两部分：被动叠力量变成先天技能（从 1 级就有，也就是学技能之前就能叠层），主动格挡变成 E 技能"肉盾"。
- 获得层数的条件：敌方英雄在帕吉 450 范围内死亡（包括被反补），或者帕吉本人拿到击杀（距离不限）。击杀幻象、带重生效果的英雄不给层数。
- 每层 +2 力量，相当于 +44 生命、+0.2 生命恢复、+2 攻击力（力量是主属性）。25 级天赋让每层变成 3 力量，同时肉盾格挡值 ×1.5。
- 手游简化：每次在范围内有敌方英雄死亡，就给帕吉一个永久加力量的计数器，头顶飘出"+1"。

### 11.3 宙斯：静电场 (Static Field)（先天）

- 触发条件：宙斯的**普攻命中**，或他的**任何技能命中**敌人（弧形闪电每一跳、雷击、神圣一跳、雷神之怒、雷云的落雷、霹雳之手的弧形闪电都会触发）。雷云和霹雳之手是否触发，是根据"技能命中即触发"的描述推断的 **(待确认)**。
- 伤害：目标**当前生命**的 `3.45% + 0.05% × 英雄等级`（1 级 3.5%、10 级 3.95%、20 级 4.45%、30 级 4.95%），魔法伤害，会被魔抗减免。对幻象的伤害按幻象减伤规则打折。
- 7.41 以前数值随雷神之怒等级提升，并有 +2% 的 25 级天赋；7.41 起两者都已移除（数据接口里还残留这个天赋的数值字段，实际已不在天赋树里）。
- 按当前生命计算，所以对满血、高血量的目标收益最大，残血时收益很小，通常作为"开局伤害"。弧形闪电冷却只有 1.6s，每次都能触发。
- 结算顺序（先算静电场还是先算技能本体伤害）**(待确认)**。手游实现建议：先按命中时的当前生命算出静电场伤害，再结算技能伤害，这样结果稳定、玩家也容易理解。
